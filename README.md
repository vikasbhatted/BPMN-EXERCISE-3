# BPMN Process Models

This repository contains BPMN diagrams created using Camunda Modeler for the Workflow Automation Engineering assignment.

## Assignment 1: Student Project Approval and Allocation
This diagram represents the student project proposal submission, validation, review, revision or rejection, and faculty guide allocation process.

## Assignment 2: Logistics and Shipment Management
This diagram represents shipment booking, validation, pickup, parcel sorting and inspection, delivery, recipient acceptance or refusal, and claim settlement.

## Tools Used
- Camunda Modeler
- BPMN 2.0
